## Phase review checklist (P2, at every milestone exit)
- [ ] Can an average user do this without documentation?
- [ ] Does it work with zero configuration on a fresh Windows 10/11 VM?
- [ ] Are new options defaulted sensibly and kept out of the basic flow (Advanced only)?
- [ ] Does every user-visible error have plain wording and one next action (mapped in `02-architecture.md` §2.5)?
- [ ] Are security defaults unchanged and invisible to the user?

Every failure is logged below with an `R-UX` ID.
